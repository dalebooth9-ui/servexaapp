- Service-role functions use `resolveCaller` (_shared/callerOrg.ts) and check each request id with `ownsRecord`/`sharesCompany`; admin counts only in the caller org — why: service role bypasses RLS.
- Handwritten-report conversion sends only job + submission ids; `_shared/jobSourceImages.ts` loads files after company/job checks and results save as drafts with `_transcribed_from` — why: no cross-company file reads, nothing auto-submitted.
- Handwritten conversion reads via `conversion: true` in ocr-job-sheet (conversionRead.ts): the browser sends a cleaned copy made by src/lib/sheetImagePrep.ts alongside the company-checked source ids; each question returns value/best_guess/confidence/box and the client sorts every question into read, check or from-job (classifyConversion) — why: real site photos need clean-up, and no question may end blank without a flag.
- Automatic customer emails from status changes (notify-customer) send only when the company's app_settings `customer_status_emails` flag for that type is true (default off); status changes are internal — why: completing a job emailed customers unasked.
